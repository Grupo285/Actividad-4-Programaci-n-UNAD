Abrir terminal y ejecutar:

```bash

```

## Objetivo del proyecto

Desarrollar un sistema orientado a objetos completamente funcional sin utilizar bases de datos, aplicando principios de encapsulación, herencia, polimorfismo y manejo avanzado de excepciones.
